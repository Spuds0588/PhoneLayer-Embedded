How it works

Intercept. Choose. Route.

1

Intercept

A single delegated listener captures every click on tel:/sms: links and .phonelayer-trigger elements — no per-link wiring.

2

Sanitize & choose

Numbers are stripped to digits (leading + kept) before they hit a strict URI handler. Visitors pick from a searchable, themed provider list.

3

Route

App providers launch via OS URI schemes; Web providers open a centered 600×700 popup. Mobile devices are bypassed entirely — native wins there.

Integration

Drop it in. Done.

One script tag before </body>. Theme via attributes on the script or per trigger.

<!-- before </body> -->
<script src="phonelayer.js"
        data-phonelayer-color="#f2a33c"
        data-phonelayer-theme="dark"></script>
Global theme — applies to every modal, including your brand color.
<!-- per-trigger override -->
<button class="phonelayer-trigger"
        data-phonelayer-to="(555) 123-4567"
        data-phonelayer-color="#4fd1c5"
        data-phonelayer-theme="light">
  Call Sales
</button>
